# Digital Clock

A modern, futuristic digital clock web application with stunning visual effects and animations. Features a sleek cyan-themed design with glowing effects, scanlines, and smooth animations.

## Features

- **Real-time Clock Display**: Shows current time in 12-hour format with hours, minutes, and seconds
- **Date Display**: Displays the full date with weekday, month, day, and year
- **Modern UI Design**: 
  - Futuristic cyan/neon color scheme
  - Glowing text effects with animated shadows
  - Decorative corner brackets
  - Animated scanline effect
  - Pulsing glow animations
  - Gradient text effects
- **Responsive Design**: Fully responsive and optimized for desktop, tablet, and mobile devices
- **Smooth Animations**: Multiple CSS animations including:
  - Glow pulse effects
  - Shine animation
  - Scanning line effect
  - Blinking dots
  - Text glow animations

## Technologies Used

- **HTML5**: Structure and markup
- **CSS3**: Styling with advanced animations and effects
- **JavaScript**: Real-time time updates
- **Google Fonts**: Orbitron font family for a digital/tech aesthetic

## Getting Started

### Prerequisites

No prerequisites required! This is a pure HTML/CSS/JavaScript application that runs directly in any modern web browser.

### Installation

1. Clone or download this repository
2. Open `index.html` in your web browser
3. That's it! The clock will start displaying the current time immediately

### Usage

Simply open `index.html` in any modern web browser. The clock will automatically:
- Display the current date and time
- Update every second
- Show the time in 12-hour format (AM/PM)

## Customization

You can easily customize the clock by modifying `style.css`:

- **Colors**: Change the cyan color (`#00ffff`) to any color you prefer
- **Font Size**: Adjust the `font-size` properties in the `.clock`, `.date`, and `.format` classes
- **Animation Speed**: Modify the `animation-duration` values in the keyframes
- **Effects**: Enable/disable specific animations by commenting out CSS rules

## Features Breakdown

### Visual Effects
- **Glow Effect**: Radial gradient background with pulsing animation
- **Corner Brackets**: Decorative corner elements for a tech aesthetic
- **Scanline**: Animated scanning line effect across the clock
- **Text Shadows**: Glowing text shadows that pulse
- **Gradient Text**: Gradient color effect on the time display

### Responsive Breakpoints
- Desktop: Full-size display (6rem font for time)
- Tablet (≤768px): Medium-size display (4rem font for time)
- Mobile (≤480px): Compact display (3rem font for time)
